**Metaprompting**
All those prompts that serve to generate new prompts 
Example: First instruction to work with Metaprompting : Tienes que generar un prompt que me permita volver a ingresarlo en ChatGPT. Second instruction to assign the context about what we want to generate:  Este prompt debe explicar cual es mi objetivo(generar una funcion especifica de Javascript).Debe permitirle a chatGpt devolver la funcion exacta que necesito.

Para lograr esto hazme todas las preguntas que necesites. Luego de recibir mis respuestas, si necesitas hacerme nuevas preguntas puedes hacerlo. Pero luego de eso deberas devolverme el prompt si o si.

Prompt:

"Create interactive JavaScript exercises for a complete beginner who is learning to code. Each exercise should include a clear explanation of the theory behind the concept, starting from the basics, and gradually progressing to more complex topics.

The user should be guided through each concept step by step. Start with variables, then proceed to operations, conditionals, loops, arrays, functions, objects, array methods, and JavaScript asynchronous programming (callbacks, promises, async-await). Mix topics in exercises as you progress to help reinforce understanding by showing how different concepts are connected.

For each topic:

Begin with an explanation of the theory, using simple language and examples.

Provide a related exercise with a real-world context (like calculating a discount on a product, or creating a to-do list app).

If the user struggles or makes a mistake, offer helpful suggestions to guide them toward the correct solution.

After the user attempts the exercise, explain the correct solution in detail.

For asynchronous JavaScript topics (callbacks, promises, async-await), include in-depth explanations and examples, ensuring the user understands how and when to use each concept.

Ensure the tone is friendly and encouraging throughout the learning process, making it feel like a fun and engaging experience."
